## Usage

A monitor is a binding with `view: 'monitor'`: it shows a property's value and has no editor. It is
created with `addBinding`, takes the usual binding options such as `label`, `precision`,
`interval`, `min` and `max`, and returns the usual binding handle, with the same search,
visibility, refresh and disposal as any other control. Presentation options go under `monitor`.

<Code
  code={`pane.addBinding(stats, 'fps', {
  view: 'monitor',
  monitor: { view: 'graph', bufferSize: 64 },
  min: 0,
  max: 144,
  precision: 0,
  interval: 32,
});`}
  language="ts"
/>

A monitor presents the values your application puts in the property; it measures nothing itself.
For several series in one graph, paging or overlays, use `addGraph`; for frame rate, frame time
and memory measured for you, use `addPerformanceMonitor`.

### Text

Text is the default view. It accepts any value: numbers show with fixed decimals set by
`precision`, other values show as text, and `null` or `undefined` shows as an em dash.

<Preview
  title="Text"
  code={`<div id="monitors-text"></div>`}
  script={`import { Pane } from '@tweakpad/devkit';
const net = { latency: 42.318, status: 'connected', region: null };
setInterval(() => { net.latency = 30 + Math.random() * 25; }, 500);
const pane = new Pane({ container: document.getElementById('monitors-text'), title: 'Network' });
pane.addBinding(net, 'latency', { label: 'Latency ms', view: 'monitor', precision: 1 });
pane.addBinding(net, 'status', { view: 'monitor' });
pane.addBinding(net, 'region', { view: 'monitor' });`}
/>

### Graph

`monitor: { view: 'graph' }` draws the recent history of a number along with its current value; a
graph of anything else throws. The history is a bounded buffer of `bufferSize` samples that keeps
equal values, so a value that holds steady draws a flat line. A line needs at least two samples.

<Preview
  title="Graph"
  code={`<div id="monitors-graph"></div>`}
  script={`import { Pane } from '@tweakpad/devkit';
const audio = { level: 0 };
let t = 0;
setInterval(() => {
  t += 0.1;
  audio.level = 0.5 + 0.35 * Math.sin(t) + 0.1 * Math.random();
}, 50);
const pane = new Pane({ container: document.getElementById('monitors-graph'), title: 'Audio' });
pane.addBinding(audio, 'level', { view: 'monitor', monitor: { view: 'graph', bufferSize: 120 } });`}
/>

### Range

`min` and `max` fix the vertical range of a graph. Without them, the range fits the visible
history with some headroom and changes only when the data leaves it or uses less than a third of
it, so the plot does not rescale on every sample. `scale` decides how that fit treats zero:
`'absolute'` always includes it, and `'relative'` hugs the data, which suits values that move
slightly around a large number.

<Preview
  title="Range"
  code={`<div id="monitors-range"></div>`}
  script={`import { Pane } from '@tweakpad/devkit';
const server = { load: 0.4, heapMb: 512 };
setInterval(() => {
  server.load = Math.min(1, Math.max(0, server.load + (Math.random() - 0.5) * 0.1));
  server.heapMb = 512 + Math.random() * 8;
}, 100);
const pane = new Pane({ container: document.getElementById('monitors-range'), title: 'Server' });
pane.addBinding(server, 'load', { view: 'monitor', monitor: { view: 'graph' }, min: 0, max: 1 });
pane.addBinding(server, 'heapMb', {
  label: 'Heap MB',
  view: 'monitor',
  monitor: { view: 'graph', scale: 'relative' },
  precision: 1,
});`}
/>

### Line, fill and guides

`color` sets the line to any CSS color, and `fill` shades the area under it, at an opacity of your
choice, or not at all. `guides` draws dashed reference lines in the binding's units, such as a
budget to stay under; a guide with the value `'average'` follows the mean of the visible history.

<Preview
  title="Line, fill and guides"
  code={`<div id="monitors-style"></div>`}
  script={`import { Pane } from '@tweakpad/devkit';
const gpu = { usage: 0.6 };
setInterval(() => {
  gpu.usage = Math.min(1, Math.max(0, gpu.usage + (Math.random() - 0.5) * 0.15));
}, 80);
const pane = new Pane({ container: document.getElementById('monitors-style'), title: 'GPU' });
pane.addBinding(gpu, 'usage', {
  view: 'monitor',
  monitor: {
    view: 'graph',
    color: '#f472b6',
    fill: 0.3,
    guides: [{ value: 0.8 }, { value: 'average' }],
  },
  min: 0,
  max: 1,
});`}
/>

### Sampling

A monitor samples on the pane's refresh: every frame by default, at the pane's interval, or only
when you call the handle's `refresh()` or write its value under manual refresh. `interval` on the
binding sets its own cadence. Hidden, collapsed, inactive-tab and off-screen monitors stop
sampling, and `refresh()` still reads a hidden one on demand.

The binding is the only thing that reads the property; a monitor adds no sampler or loop of its
own. A graph's history belongs to the binding rather than to its element, so a graph that leaves
the screen releases its plot and redraws the retained history when it returns. Graphs are drawn
by the same plot as `addGraph`, and disposing the binding releases it.

<Code
  code={`const pane = new Pane({ title: 'Job', refresh: 'manual' });
const progress = pane.addBinding(job, 'progress', { view: 'monitor', monitor: { view: 'graph' } });
job.onStep(() => progress.refresh());`}
  language="ts"
/>

### Writing from code

The user cannot edit a monitor, but the application can: writing the handle's `value` updates the
original property and fires the same `change` and `finish` events as other controls. Values the
monitor samples on its own refresh the display without firing `change`.

<Code
  code={`const frameTime = pane.addBinding(stats, 'frameMs', { view: 'monitor', precision: 2 });
frameTime.on('change', ({ value }) => log(value));
frameTime.value = 0;`}
  language="ts"
/>

### In a row

A monitor is an ordinary binding item in `addRow`, so it can sit beside the actions that affect
it. Searching for the monitor's name or label keeps its whole row.

<Preview
  title="In a row"
  code={`<div id="monitors-row"></div>`}
  script={`import { Pane } from '@tweakpad/devkit';
const queue = { pending: 0 };
setInterval(() => { queue.pending += Math.floor(Math.random() * 3); }, 400);
const pane = new Pane({ container: document.getElementById('monitors-row'), title: 'Uploads' });
pane.addRow({
  name: 'queue',
  items: [
    { type: 'binding', target: queue, key: 'pending', label: 'Pending', view: 'monitor', precision: 0 },
    { type: 'button', title: 'Clear', width: 'auto', onClick: () => { queue.pending = 0; } },
  ],
});`}
/>
